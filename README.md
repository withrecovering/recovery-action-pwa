# 작은 행동 회복 기록

작은 행동 회복 기록은 현실에서 실제로 한 행동의 시작과 끝을 가볍게 남기는 개인용 회복 기록 PWA입니다.

이 앱의 핵심은 생산성 점수를 높이는 것이 아니라, 실제 행동과 기록이 가능한 한 부드럽게 일치하도록 돕는 것입니다.

## 핵심 방향

- 좋은 행동만 기록하지 않습니다.
- 공부, 휴식, 식사, 운동, 딴짓도 기록할 수 있습니다.
- 시작 버튼과 실제 행동 시작을 맞추는 연습을 합니다.
- 끝 버튼과 실제 행동 종료를 맞추는 연습을 합니다.
- 기록은 평가가 아니라 현실 접촉의 흔적입니다.
- 기록이 어긋나도 실패가 아니라 나중에 정정할 수 있는 데이터 오류로 봅니다.

## 현재 안정 기준

현재 안정 기준은 v22-focus-overlay 계열입니다.

앞으로 업데이트는 한 번에 하나씩, 작은 단위로 진행합니다.

## 개발 원칙

- 기록은 행동보다 가벼워야 합니다.
- 앱은 자기비난을 늘리는 도구가 아니라 현실 접촉을 돕는 도구여야 합니다.
- 기능 추가보다 안정적인 시작/종료 기록 루프를 우선합니다.
- 큰 기능은 바로 넣지 않고 작은 PR로 나누어 검증합니다.
